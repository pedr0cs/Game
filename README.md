# Game

Projeto pessoal de um jogo no estilo asteroids com elementos de RPG, desenvolvido em e HTML.

## Sobre o projeto

Um jogo web onde o jogador enfrenta ondas de inimigos. O foco é no gameplay core (sobrevivência + upgrades).

## Roadmap

- [x] **Fase 1** — Protótipo em terminal: classes Player e Enemy, inimigo se move e é derrotado
- [x] **Fase 2** — Boneco se movendo na tela (Canvas + teclado)
- [x] **Fase 3** — Inimigos no frontend
- [x] **Fase 4** — Sistema de dano e morte
- [x] **Fase 5** — Virando nave espacial

## Tecnologias

- HTML + Canvas API (frontend)
- JavaScript (movimento, game loop)
